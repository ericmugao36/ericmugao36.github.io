## Make your existing website or software work better for you

You may already have a website, dashboard or application that works but needs changes to reflect your business, school or brand.

I help customize existing code so that suitable changes can be made without rebuilding an entire project unnecessarily.

The service is intended for individuals and organizations that need practical modifications to an existing digital solution.

## What I can help change

### Branding and business information

- Business or school names.
- Logos and brand elements.
- Contact information.
- Colours and other visual details.
- Organization-specific labels and text.

### Website and dashboard content

- Page headings and descriptions.
- Navigation labels and links.
- Product and service information.
- Text, images and other content.
- Layout adjustments within the existing design.

### Application configuration

- Supported settings and options.
- Configurable application details.
- Appropriate changes to existing forms and interfaces.
- Selected functionality improvements.

### Code organization and documentation

- Reviewing relevant sections of an existing codebase.
- Simplifying suitable repeated code.
- Fixing identified issues within the agreed scope.
- Providing basic documentation and handover guidance.

## What the service does not automatically include

A customization request is not automatically a complete redesign, major application rebuild, ongoing maintenance contract or guarantee that every existing software issue can be fixed.

The codebase must be reviewed before the scope and feasibility of requested changes can be confirmed.

## Pricing

Projects start from **KSh 10,000**.

The final quotation depends on:

- Size and condition of the existing codebase.
- Number and complexity of requested changes.
- Whether the project has adequate documentation.
- Testing and deployment requirements.
- Additional functionality or integrations.

## How it works

1. You explain the website, dashboard or application you want changed.
2. We review the relevant project files and requirements.
3. I identify the changes that can reasonably be made.
4. We agree on the scope, price and timeline.
5. I make and test the agreed modifications.
6. You receive the updated work and handover guidance.

## Discuss your project

Contact Eric with a short explanation of your existing software and the changes you want to make.

Where possible, include a link to the website or a description of the application. We can then discuss the next steps and a suitable quotation.
