## Make existing software work better for you

You may already have a website, dashboard or application that works but needs adjustments to suit your school, business or brand.

I help customize existing code so that appropriate changes can be made without rebuilding the entire project.

### What I can help change

- Business or school names and details.
- Branding, logos and visual presentation.
- Headings, labels and page content.
- Configurable settings for supported features.
- Repetitive editing tasks that could be simplified.
- Documentation and handover guidance.

### Pricing

**Starting at KSh 10,000.**

The final quotation depends on the codebase, the requested changes, testing requirements and project complexity.

### How it works

1. You explain what needs to change.
2. We review the project and agree on the scope.
3. I make the agreed modifications and test them.
4. You receive the updated code and handover guidance.
