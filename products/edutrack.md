## Make academic progress easier for schools and parents to understand

EduTrack is a school assessment dashboard designed to help schools organize learner results and communicate academic progress more effectively.

Instead of treating assessment as a record-keeping exercise, EduTrack helps schools bring together student results, teacher comments and parent access in one organized system.

The aim is simple: make academic information easier to manage for schools and easier to understand for parents.

## Key features

- **Student assessment records:** Organize learner assessment results in a structured system.
- **Academic reports:** Make student performance information easier to review and communicate.
- **Teacher comments:** Give teachers a way to add comments about learners' academic progress.
- **Parent access:** Allow parents to view reports relating to their children.
- **School management:** Support school and teacher administration within the assessment system.
- **Organized reporting:** Reduce reliance on scattered assessment records and manual communication.

Available functionality depends on the selected package and agreed implementation scope.
